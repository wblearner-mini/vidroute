# Code of conduct

vidroute adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful and constructive, assume good intent, and keep discussions about the work.
Harassment, discrimination, personal attacks and publishing others' private information are not
acceptable in any project space (issues, pull requests, discussions).

Report unacceptable behaviour privately to the maintainers through GitHub
(<https://github.com/wblearner-mini>); reports are handled confidentially. Maintainers may remove
content and restrict participation, following the enforcement guidelines of the Covenant.
